# e-plantShopping

## Paradise Nursery Shopping Application

Paradise Nursery Shopping Application is a modern React and Redux based e-commerce web application designed for plant lovers. The application allows users to browse a wide variety of indoor and outdoor plants, add products to the shopping cart, manage quantities dynamically, and calculate total cart amounts efficiently.

---

## Features

### Product Listing
- Display multiple plants with images, names, and prices
- Organized product categories
- Attractive and responsive product cards

### Shopping Cart
- Add products to cart
- Increase and decrease item quantity
- Remove items from cart
- Dynamic cart total calculation
- Real-time cart item updates

### User Interface
- Responsive landing page
- Navigation bar for easy browsing
- "Get Started" button functionality
- Clean and modern design
